# Package documentation

Install and use all three packages from one documentation site.

| Package | Version | Purpose | Documentation |
| --- | --- | --- | --- |
| `jin-frame` | 6.0.0 | Execute handwritten or generated HTTP requests | [Getting started](./getting-to-start) |
| `@jin-frame/generator-cli` | 1.0.0 | Generate types and frames from OpenAPI on the command line | [CLI guide](./generator-cli/) |
| `@jin-frame/generator-core` | 1.0.0 | Build a generation pipeline in code | [Core guide](./generator-core/) |

Start with jin-frame to write request classes by hand. Use the CLI with an OpenAPI specification, or use core to integrate generation into custom tooling. Generators run during development; generated clients use jin-frame at runtime.
